# Eval datasets

- `manual_seed.jsonl` — hand-written questions with the sutta uid(s) that answer them.
  Highest-value rows; add questions you would genuinely ask. Relevance for these rows is
  document-level (any chunk of the listed suttas counts as relevant).
- `retrieval_v1.jsonl` — generated by `python -m evals.generate` (seed + synthetic merged).
- `corpus_manifest_v1.json` — frozen corpus snapshot; `evals.run` verifies against it.
- `results/` — eval run outputs keyed by git sha; commit the baseline ones referenced in docs.

The dataset is also synced to Langfuse (`python -m evals.sync`) so retriever comparison runs
show up in the Langfuse datasets UI. **The JSONL here stays the source of truth** — items
upsert by row id, so re-syncing after edits is safe and idempotent.

Schema: see `evals/dataset.py` (`EvalRow`). Validate after editing:
`poetry run pytest tests/evals/test_seed_file.py`
